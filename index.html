      기록 상세

      전투 카드 선택 분석

      일반·엘리트·보스 전투에서 선택한 횟수 기준으로 유형별 상위 3장을 표시합니다. 타격·수비 등 시작 카드는 제외합니다.

      채용률은 선택 / 제시 횟수, 선택 런 승률은 해당 카드를 선택한 승리 / 승패 확인 런 수입니다.

      기간은 한국 시간 기준 런 시작일에 적용됩니다. 최근 기간에는 오늘이 포함되며, 커뮤니티 채용률은 Spire Codex 제공 범위를 따릅니다.

      플레이 성향 분석

      엘리트 비율은 장소 유형이 확인된 방문을, 회복·강화 비율은 휴식 행동이 기록된 방문을 기준으로 계산합니다.

      승리·패배 비교

      지표승리패배차이 (승리 − 패배)
